# Equipment and Technology Policy

## Purpose

This policy outlines the standards for company-provided equipment, personal device usage, and technology management.

## Company-Provided Equipment

### Standard Equipment
All full-time employees receive:
- Laptop computer
- Charger and cables
- Headset for video calls
- Monitor (upon request)

### Specialized Equipment
Available for specific roles:
- Additional monitors
- Standing desk converters
- Specialized software
- Mobile devices

### Equipment Request Process
1. Submit request through IT portal
2. Manager approval required
3. IT procurement and provisioning
4. Delivery within 5 business days

## Equipment Care and Maintenance

### Employee Responsibilities
- Use equipment for business purposes
- Keep equipment clean and in good condition
- Protect from theft and damage
- Report issues promptly
- Return equipment upon termination

### Prohibited Activities
- Installing unauthorized software
- Attempting repairs without IT approval
- Using equipment for illegal activities
- Removing company-installed software

### Damage and Loss

**Accidental Damage**:
- Report within 24 hours
- IT assesses repair or replacement
- Deductible may apply for repeated incidents

**Lost Equipment**:
- Report immediately
- File police report if stolen
- May be subject to replacement fee

**Theft**:
- File police report
- Report to IT Security immediately
- IT provides replacement equipment

## Personal Device Policy (BYOD)

### Eligibility
Employees may use personal devices for work with IT approval.

### Security Requirements
- Password or biometric lock required
- Company MDM software must be installed
- Keep OS and apps updated
- Separate work and personal data
- Remote wipe capability for work data

### Supported Devices
- iOS 14+
- Android 12+
- macOS 12+
- Windows 11

### Data Handling
- Do not store sensitive company data on personal devices
- Use company-approved apps for work
- Enable remote wipe capability

## Software and Licensing

### Approved Software
Use only company-approved software:
- Check IT portal for approved list
- Submit request for new software
- IT validates licensing and security

### Software Installation
- Company computers: IT installs software
- Personal devices: Download from approved app stores
- No pirated or unauthorized software

### License Management
- Licenses are company property
- Do not transfer or copy licenses
- Return licenses upon device return

## Internet and Network Access

### WiFi Networks
- Company network: Secure, authenticated access
- Guest network: For visitors only
- Do not connect unauthorized routers

### VPN Usage
Required for:
- Accessing company systems remotely
- Working with sensitive data
- Traveling internationally

### Bandwidth Usage
- Business use prioritized
- Limit large downloads during work hours
- No streaming or downloads of illegal content

## Email and Communication Tools

### Company Email
- Official company communication channel
- Professional tone required
- Do not send confidential data unencrypted
- Monitor regularly during work hours

### Approved Communication Tools
- Slack for instant messaging
- Microsoft Teams for video conferencing
- Zoom for external meetings
- Company email for formal communications

### Personal Use
- Limited personal use acceptable
- No illegal or inappropriate content
- Do not speak on behalf of company

## Technology Security

### Password Requirements
- Minimum 12 characters
- Mix of uppercase, lowercase, numbers, symbols
- Change every 90 days
- Unique password for each account
- Use password manager

### Multi-Factor Authentication (MFA)
- Required for all company accounts
- Use authenticator app or hardware token
- Keep backup codes secure

### Data Protection
- Lock computer when away
- Encrypt sensitive files
- Use secure file sharing
- Delete data securely when no longer needed

## Remote Work Equipment

### Stipends and Reimbursements
- Internet stipend: $50/month
- Home office setup: Up to $500 one-time

### Equipment Return
- All equipment returns upon termination
- Schedule return with IT
- Data wiped before return

## Hardware Disposal

### Return Procedures
- Contact IT before last day
- Back up personal files
- IT wipes and reclaims equipment
- Receipt provided

### Recycling
- Electronic waste recycled responsibly
- Data destruction verified
- Environmental compliance
